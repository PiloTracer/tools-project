# Accessibility audit — Batch J CRM Pipeline

**Date:** 2026-06-19
**Standard:** WCAG 2.2 Level AA

---

## Critical findings (fixed)

| Issue | Fix |
|-------|-----|
| DataTable `<tr onClick>` not keyboard accessible | Added `tabIndex={0}`, `role="button"`, `onKeyDown` (Enter/Space) |
| Sortable `<th>` headers not keyboard accessible | Added `tabIndex={0}`, `onKeyDown` (Enter/Space) |

## Serious findings (fixed)

| Issue | Fix |
|-------|-----|
| No skip-to-content link in AppShell | Added skip link as first focusable element, `#main-content` target |
| DropdownMenu lacks focus management and arrow-key navigation | Added focus-to-first on open, restore-to-trigger on close, ArrowUp/ArrowDown nav |
| Form errors not associated via `aria-describedby` | Added `role="alert"` and unique `id` to all error messages |
| Tab panel lacks ARIA semantics (Clients detail) | Added `role="tablist"`, `role="tab"`, `aria-selected`, `aria-controls`, `role="tabpanel"`, `aria-labelledby` |

## Verdict: PASS

**Updated HANDOFF_UI:** Yes
**Blocking complete:** No — all critical/serious issues resolved.
