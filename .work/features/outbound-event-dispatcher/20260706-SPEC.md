# Outbound Event Dispatcher — Feature SPEC

**Status:** Approved
**Owner:** Engineering
**Related plans:** `proposal_tools_project_ecosystem_hub` (Modification 1)

## 1. Purpose
Fire HMAC-signed outbound HTTP POSTs to registered webhook URLs whenever key business events occur (prospect stage changes, client creation, ticket status changes, task completion). Satellite apps (OpsBoard, SignFlow, LedgerLite) subscribe to events instead of polling the Agent Query API.

## 2. In scope / Out of scope
**In scope:**
- `webhook_subscriptions` table (id, url, events[], hmac_secret)
- `app/services/webhook_dispatcher.py` — async dispatch with retry + backoff
- Wiring at event-producing call sites: prospects stage transition, client created, ticket status change, task done
- Admin CRUD API for subscriptions: `GET/POST/DELETE /v1/admin/webhook-subscriptions`
- HMAC-SHA256 signing using per-subscription secret

**Out of scope:**
- Delivery exactly-once (at-least-once for V1)
- Webhook management UI (admin API only)
- Retry across process restarts (in-memory retry queue)
- Subscription verification/ping endpoint

## 3. Behavioural spec
R1 — `POST /v1/admin/webhook-subscriptions` creates a subscription with url, events list, and generates a random HMAC secret. Admin-only (requires superuser).

R2 — `GET /v1/admin/webhook-subscriptions` lists all subscriptions (secrets masked).

R3 — `DELETE /v1/admin/webhook-subscriptions/{id}` removes a subscription.

R4 — When an in-scope event occurs, `dispatch_event(event_type, payload, db)` queries matching subscriptions and POSTs to each URL.

R5 — Payload is JSON with `{ event, timestamp, data }` signed via `X-Webhook-Signature: sha256=<hmac-hex>`.

R6 — Failed deliveries retry up to `max_retries` times with exponential backoff (async sleep, in-memory queue).

R7 — Wire into `prospects.py` stage transitions, `clients.py` creation, `tickets.py` status changes, `tasks.py` status changes.

## 4. Data model
```sql
CREATE TABLE IF NOT EXISTS webhook_subscriptions (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    label VARCHAR(100),
    url TEXT NOT NULL,
    events TEXT[] NOT NULL DEFAULT '{}',
    hmac_secret TEXT NOT NULL,
    max_retries INTEGER NOT NULL DEFAULT 3,
    last_delivered_at TIMESTAMPTZ,
    created_by UUID REFERENCES users(id),
    created_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
```

## 5. APIs
`POST /v1/admin/webhook-subscriptions` — `{ url, events: [...], label? }` → `201`
`GET /v1/admin/webhook-subscriptions` → list
`DELETE /v1/admin/webhook-subscriptions/{id}` → `204`
