# Tutorial: Your First Project

Walk through creating a project, adding tasks, and collaborating.

## Step 1: Create a project

1. Sign in to tools-project.
2. Click **Projects** in the top navigation bar.
3. Click **New project**.
4. Enter:
   - **Name:** "My First Project"
   - **Key:** "MFP" (this enables auto-generated refs like `MFP-1`)
   - **Description:** "A test project to learn the system"
5. Click **Create**.

## Step 2: Create tasks

1. Open your new project.
2. Go to the **Tasks** tab.
3. Click **Add task** and enter:
   - **Title:** "Research requirements"
   - **Status:** "In Progress"
4. Add another task: "Build prototype", status "Todo".
5. Drag "Build prototype" to "In Progress" on the Kanban board.

Notice that each task gets a ref (`MFP-1`, `MFP-2`).

## Step 3: Add a comment

1. Click on a task to open its detail page.
2. In the activity section, type a comment: "Started researching competitor solutions."
3. Use `@` to mention another user (if any exist).
4. Click **Post**.

## Step 4: Create a ticket

1. Go to the **Tickets** tab.
2. Click **New ticket**.
3. Enter:
   - **Title:** "Bug: login page crashes on invalid email"
   - **Queue:** "bugs"
   - **Priority:** "High"
4. The ticket gets ref `MFP-T-1`.

## Step 5: Check your inbox

1. Click **Inbox** in the top nav.
2. Any @mentions or notifications appear here.
3. You can triage items into tasks or tickets directly from the inbox.

## Step 6: Invite a team member

1. Go to **Project Settings → Members**.
2. Enter a team member's email and assign them a role (Member, Maintainer, etc.).
3. They now have access to the project.
