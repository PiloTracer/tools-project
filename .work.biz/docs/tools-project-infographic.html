THE HEADLINE

How commits auto-link to tasks

The headline feature

Every task has a ref. A git hook prepends it to the commit subject. The poller links it back.

Works identically for a human typing git commit -m and for an AI coding agent running git commit programmatically. This app was built using .ai, .ai.ui, and .ai.biz frameworks — every agent commit lands on the right task.

# branch: feature/PROJ-456-login $ git commit -m "Add login form" # → hook rewrites the subject: PROJ-456: Add login form # → on GitHub sync, auto-linked to task PROJ-456
