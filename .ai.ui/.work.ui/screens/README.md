# Screen SPECs (`.work.ui/screens/`)

> **Navigation only.** SPEC folders are created by **`@ui-screen-spec create - <slug>`** at **repo root** `.work.ui/screens/<slug>/`.

Binding rules: `.ai.ui/standards/*SCREEN_SPEC*`

| Action | Command |
|--------|---------|
| Create | `@ui-screen-spec create - <slug>` |
| Review | `@ui-screen-spec review - .work.ui/screens/<slug>/YYYYMMDD-SCREEN-SPEC.md` |

**Do not** place screen SPECs in `.work/features/` (domain SPECs only).
