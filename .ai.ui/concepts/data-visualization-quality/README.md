# UIS-09 — Data visualization quality

**Id:** UIS-09
**Use when:** Analytical dashboards, report screens, any screen with charts, KPIs, or data-driven graphics.

**Prompt:** [`prompt.md`](prompt.md)

**Goal:** Charts that are truthful, readable at every breakpoint, colorblind-safe, and accessible — no misleading scales, chart junk, or empty canvas.
