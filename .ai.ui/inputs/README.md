# Inputs — curated design references

**Location:** `.ai.ui/inputs/` (framework). **Project content:** add under your repo copy; do not commit secrets or licensed assets without rights.

| Folder | Purpose |
|--------|---------|
| `brand/` | Logo usage, color PDFs, typography exports (reference) |
| `design-references/` | Approved screenshots, competitor refs (annotated) |
| `inspiration/` | Mood boards — **not** binding spec |

**Rules:**

1. Agents read inputs for context; **screen SPECs** remain binding for implementation.
2. No API keys, Figma tokens, or private URLs with embedded auth in committed files.
3. Prefer linking to internal design tool with access note in HANDOFF_UI.

**Manifest (optional):** `inputs/MANIFEST.txt` — path, source, date added.
