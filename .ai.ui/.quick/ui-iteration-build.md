# UI Build Iteration — Plan, Start, Continue, Complete

## Plan a milestone

```text
@ui-component-build plan - S0
@ui-component-build plan - S1
@ui-component-build status
```

## Build incrementally

```text
@ui-component-build start
@ui-component-build continue - 1
@ui-component-build continue - 3
@ui-component-build continue - until complete
```

## Fix specific items

```text
@ui-component-build continue - until blocked
@ui-component-build continue - fix primary action contrast
```

## Build chart/dashboard components

```text
@ui-component-build continue - add KPI row with sparklines
@ui-component-build continue - add line chart for revenue trend
@ui-component-build continue - add data table with sort and export
@ui-component-build continue - add filter bar with date range picker
```

## Complete milestone (runs verify gates)

```text
@ui-component-build complete
```
