# Quick-reference cheat sheets (`.quick/`)

**Location:** `.ai.ui/.quick/`
**Purpose:** Copy-paste command snippets for the most common UI Design OS workflows — no need to open full skill docs for routine tasks.

Each file is a focused, one-page reference for a specific workflow pattern:

| File | When to open |
|------|--------------|
| [`greenfield-start.md`](greenfield-start.md) | Starting a new UI project from scratch — bootstrap → foundation → specs → build |
| [`analytical-dashboard.md`](analytical-dashboard.md) | Building a dashboard page with charts, stats, graphs, and reporting |
| [`bootstrap-existing.md`](bootstrap-existing.md) | Adding UI Design OS to an existing project with a codebase already in place |
| [`screen-spec-workflow.md`](screen-spec-workflow.md) | Intake, create, review, or amend a screen SPEC (including §14 data viz) |
| [`ui-iteration-build.md`](ui-iteration-build.md) | Plan → start → continue → complete a UI build milestone (including chart components) |
| [`pre-ship-verify.md`](pre-ship-verify.md) | All verification gates before shipping: visual, a11y, plan audit, concept checks |
| [`concept-checks.md`](concept-checks.md) | Running UIS-01 through UIS-09 concept prompts on UI work |
| [`deploy-to-project.md`](deploy-to-project.md) | Deploy .ai.ui into a target project (files-only or full repo) |

**Not a replacement for skill docs.** For full protocols, gates, and edge cases, open `skills/<id>/skill.md`.
