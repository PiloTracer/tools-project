# Screens (pointer)

**Screen SPECs live in [`.work.ui/screens/`](../.work.ui/screens/)** at the **application repo root**, not under `.ai.ui/`.

| Action | Command |
|--------|---------|
| Create SPEC | `@ui-screen-spec create - <slug>` → `.work.ui/screens/<slug>/YYYYMMDD-SCREEN-SPEC.md` |
| Review | `@ui-screen-spec review - .work.ui/screens/<slug>/…` |

Binding standard: `.ai.ui/standards/*SCREEN_SPEC*`

Domain/API SPECs remain in `.work/features/` (Agent OS).
